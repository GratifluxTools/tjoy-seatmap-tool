# T・ジョイ 座席表の解析メモ

対象: 新宿バルト9(スクリーン3)、T・ジョイ エミテラス所沢(スクリーン 1・2・3・4・11)。梅田・京都は座席表の HAR 未取得。

## 座席ページ
- URL: `https://tjoy.jp/<劇場スラッグ>/reservation/choice_seat`。上映回ボタン → `…/reservation/index/<上映ID>/<作品コード>/<スクリーン>/<日付>?type=film|event`(302)の後に表示される。
- 座席は HTML の画像マップ `<img usemap>` の `<area>` で書かれている。
  - `id="A-6"`(行-番号)、`data-coords="x1,y1,x2,y2"`(公式座席表画像の画素座標)、`type-seat`(席種)、`add-change`(追加料金・円)、`seat-group`(ペア/トリオ)、`class`(`seat-select` / `sold-out`)。
- 公式の座席表画像: `https://cdn.tjoy.jp/images/_up/theater/<劇場コード3桁>_<スクリーン2桁>_<日付>.png`(新宿=140、所沢=200)。座席は画像に描き込み済み。`tjoy.jp/img/front/images/theater/<コード>/map_NN.png` と同一(所沢1・2・3・4・11はファイルサイズが一致)。
- 席種アイコン(凡例用): `/img/front/images/seat/icn_*.png`。

## 席種コード
| コード | 内容 | 追加料金 | 根拠 |
|---|---|---|---|
| 1 | 一般席(幅40px・肘掛けなし) | 0 | 所沢・新宿。座席表画像で確認 |
| 5 | 一般席(幅50px・肘掛け付き) | 0 | 所沢4の座席表画像の中央ブロックと一致 |
| 2 | エグゼクティブ | +1,000 | 所沢1・2・3の案内 |
| 3 | プレミア | +500 | 所沢11の案内 |
| 11 | リクライニング(最前列A) | +200 | 所沢1・2の案内 |
| 14 | カウンター(最後列L) | +200 | 所沢11の案内 |
| 1 + seat-group 2件 / 3件 | ペア / トリオ | 0 | 所沢4(凡例アイコン icn_type2 / icn_type6) |

## 検算
- 座席ページの「シアターN ○○席 +(車椅子△席)」と座標の件数が、所沢1・2・3・4・11と新宿3で全件一致。
- 車いす席は座標に含まれない(所沢4は車いす4席。座席表画像では行Aの両端)。

## 映画名欄の注記(特別設備)
- 映画名欄 `.seat-info-content-ttl` の【 】の中に、上映回の設備が書かれる(例: `【Dolby Atmos】 【DolbyAtmos】ゴジラ`)。
- 「ご案内」の文章(IMAX・MX4Dなど)は全体の案内で、上映回ごとの情報ではないため使わない。
- 表示名は公式の表記に合わせる(例: IMAX → IMAX®、Dolby Atmos → Dolby Atmos®)。座席ページにはレーザー/デジタルの区別が無いため IMAX® とする。

## 制約
- 座席表画像が HAR に無い画面は、公式風を作れない(プレーンで出力)。
- 座席ページには車いす席の位置が無い。
