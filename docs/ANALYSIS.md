# T・ジョイ 座席表・スケジュールの解析メモ

対象: 新宿バルト9（シアター3）、T・ジョイ エミテラス所沢（シアター1・2・3・4・11）。梅田・京都はスケジュールのみ確認。

## 1. 座席表（座席選択ページ）

- URL: `https://tjoy.jp/<劇場スラッグ>/reservation/choice_seat`（予約リダイレクト `…/reservation/index/<上映ID>/<作品コード>/<スクリーン>/<日付>?type=film|event` の302の後に表示）
- HTMLに座席が入っている（XHRなし）。座席は画像マップ `<img usemap="#image-map">` の `<area>`。
  - `id="A-12"`（行記号-番号）、`data-coords="x1,y1,x2,y2"`（1倍の画像座標）、`type-seat`（席種）、`add-change`（追加料金・円）、`seat-group`（ペア/トリオ）、`class`（`seat-select` / `sold-out`）。
- 公式の座席表画像: `https://cdn.tjoy.jp/images/_up/theater/<劇場コード3桁>_<スクリーン2桁>_<日付>.png`（新宿=140、所沢=200）。HARでは本体が省かれる（Fiddlerの容量上限）。
  - 同じ画像は `https://tjoy.jp/img/front/images/theater/<コード>/map_<NN>.png` でも配布されており、所沢1・2・3・4・11は、ファイルサイズがcdnの画像と完全に一致（61983 / 52341 / 49715 / 53516 / 53542 バイト）。座席座標（data-coords）もこの画像の画素座標に収まる。
  - 新宿3（140_03）は本体がどのHARにも含まれないため、公式画像は未入手。
- 座席アイコン（凡例）: `/img/front/images/seat/icn_*.png`。HARに本体があり、通常・ペア・トリオ・エグゼクティブ・プレミア・リクライニング・車椅子マーク・予約済みを含む。

### 検算
- ページ内の一覧「シアターN ○○席 +（車椅子△席）」と座標の件数が、所沢1・2・3・4・11と新宿3で全件一致（tests/test_tjoy.py）。
- 車椅子席は座標に含まれない（例: 所沢4は車椅子4席。フロアマップ上では行Aの両端）。

### 座席ページに含まれる情報
- 上映日・時刻・劇場名・シアター番号: `上映日 11/12（木）08:50～11:20 劇場 T・ジョイ エミテラス所沢 シアター ４`
- 作品名: `.seat-info-content-ttl`
- 全シアターの座席数（車椅子含む）の一覧

## 2. スケジュール（劇場トップ）

- `https://tjoy.jp/<スラッグ>` のHTMLに、その日の上映回がすべて入っている（XHRなし）。
- 作品: `div.card-body.film-content#film-<作品コード>`（映画）、`section#event-<コード>`（イベント）。
- 上映回: `li.theater-item`（シアター名は `.theater-name a`、時間は `.schedule-time`、状態は `.schedule-status`）。
- 予約リンク: `onclick` の `/<スラッグ>/reservation/index/<上映ID>/<作品コード>/<スクリーン>/<日付>?type=film|event`。
- 日付: 基準日は `input#showDate`。予約リンクがある上映回だけ、その回の日付がURLに入る。
- 劇場スラッグ: `shinjuku_wald9`、`t-joy_emiterrace_tokorozawa`、`t-joy_umeda`、`t-joy_kyoto`。

## 3. 既知の制約
- 背景画像（通路・出入口・スクリーン）はHARに含まれない場合がある。その場合は座席のみの描画（`--background` で公式画像を指定可能）。
- 座席の状態（予約済み）は描画しない（全席空席）。
- 車椅子席は座標が無いため描画しない（人数のみ表示）。
